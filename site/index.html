Install

iLoader X is an unsigned IPA: install it with an app that signs, or with TrollStore.

Add to SideStoreAdds the source; install and refresh iLoader X from it Add to AltStoreSame source, for AltStore Classic and PAL Install in LiveContainerRuns it inside LiveContainer, without its own App ID Install with TrollStorePermanent, on the iOS versions TrollStore supports Download the IPAFor Sideloadly, iLoader, Feather, KSign…

First run

  1. Get LocalDevVPN from the App Store and connect it: iLoader X works through it.
  2. On iOS 27, the iPhone pairs with itself: follow the steps in the app and type the code into Settings › Privacy & Security › Developer Mode.
  3. On iOS 17.4 to 26, import a pairing file made on a computer (jitterbugpair or pymobiledevice3); the app walks you through it.
  4. Sign in with your Apple ID, then pick SideStore, LiveContainer or your own IPA under Install.
Not the official SideInstaller iLoader X is a fork of SideInstaller by FrizzleM, with its own name, bundle ID and icon, and isn't affiliated with FrizzleM. Only install iLoader X from this page or from github.com/iamgasgass/iLoaderX: a copy from anywhere else may have been changed to steal your Apple ID.
