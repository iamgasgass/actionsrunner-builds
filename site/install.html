Install iLoader X

Open this page on the iPhone you're setting up. Pick how: with no computer at all, or from an app that already sideloads.

siboot (by FrizzleM, MIT) installs iLoader X from the iPhone itself, signed with your own Apple account: no computer and no certificate.

iOS 27+ Wi-Fi Developer Mode on An Apple account
  1. Get the apps

    Install rootshell, Open Minis and LocalDevVPN, all free on the App Store.

  2. Pair in rootshell

    In rootshell turn on Settings › Location Diary Mode › Session Only, then tap Local Shell and Open at the top right, and run these one line at a time:

    curl -fsSLO https://raw.githubusercontent.com/FrizzleM/siboot/main/rootshell/bin/siboot-pair.wasm
    ifconfig en0 > ifconfig.txt
    ./siboot-pair.wasm

    Open Settings › Privacy & Security › Developer Mode, scroll to the bottom, tap Pair with siboot, and enter your passcode and the code rootshell shows. Leave rootshell running.

  3. Install from Open Minis

    Connect LocalDevVPN. In Open Minis tap the console icon at the top right, then Shell Terminal, and run:

    wget -qO- https://raw.githubusercontent.com/FrizzleM/siboot/main/minis/install.sh | sh -s -- --ipa https://github.com/iamgasgass/iLoaderX/releases/latest/download/iLoaderX.ipa

    The --ipa part makes siboot install iLoader X instead of SideInstaller. Type the transfer code rootshell shows (only the first time), then your Apple account email, password and verification code. Keep Minis open until it says it's done. The first time, trust your Apple account in Settings › General › VPN & Device Management.

  4. Open iLoader X

    Open it from the Home Screen (siboot's “Open SideInstaller” link is for SideInstaller: ignore it). With LocalDevVPN connected, sign in with your Apple account and tap Install SideStore or Install SideStore + LiveContainer.

To reinstall or refresh iLoader X later, run this in Open Minis (plain siboot would install SideInstaller):

siboot --ipa https://github.com/iamgasgass/iLoaderX/releases/latest/download/iLoaderX.ipa

No Developer Mode switch in Settings? Once paired, siboot developer-mode makes it appear, and siboot developer-mode --turn-on turns it on.

After the install

First run

The app walks you through it; this is what to expect.

  1. Connect LocalDevVPN

    Get LocalDevVPN from the App Store and connect it: iLoader X works through it.

  2. Pair

    On iOS 27 the iPhone pairs with itself: type the code into Settings › Privacy & Security › Developer Mode. On iOS 17.4 to 26, import a pairing file made on a computer.

  3. Sign in and install

    Sign in with your Apple ID, then pick SideStore, LiveContainer or your own IPA under Install.

Not the official SideInstaller
iLoader X is a fork of SideInstaller by FrizzleM, with its own name, bundle ID and icon, and isn't affiliated with FrizzleM. Only install iLoader X from this page or from github.com/iamgasgass/iLoaderX: a copy from anywhere else may have been changed to steal your Apple ID.
