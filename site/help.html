Help

Answers to what comes up most. Still stuck? Report it from the app: it attaches the log for you.

A certificate shows as revoked, and apps won't install

On a free Apple ID each signing app tends to ask Apple for a certificate of its own, and a new one can revoke the others. Use one certificate everywhere:

  1. In iLoader X, Tools › Certificates › Load certificates: check that one says “iLoader X signs with this one”.
  2. Install SideStore + LiveContainer from iLoader X: SideStore gets iLoader X's certificate.
  3. Open SideStore inside LiveContainer once, then in LiveContainer's Settings tap Import Certificate From SideStore.
  4. Don't sign with another tool that makes its own certificate on the same Apple ID.
How do I pair on iOS 17.4 to 26?

Only iOS 27 pairs with itself. Below it, make a pairing file once on a computer with jitterbugpair or pymobiledevice3, then import it in iLoader X (Tools › Pairing). From iOS 26.4, use a remote pairing file.

What are the limits of a free Apple ID?

Apps signed with a free Apple ID last 7 days and must be refreshed; SideStore and iLoader X can do it on the device. A free account can have 3 sideloaded apps at once and register 10 App IDs a week. LiveContainer runs many apps in one, so they don't count toward the 3.

There's no Developer Mode switch in Settings

iLoader X can make it appear: Settings › Developer Mode in the app. With siboot, run siboot developer-mode in Open Minis, or siboot developer-mode --turn-on to turn it on (the iPhone restarts).

How do I update iLoader X?

The app shows a banner when a new version is out. With the source added, SideStore or AltStore shows the update too. With siboot, run siboot --ipa https://github.com/iamgasgass/iLoaderX/releases/latest/download/iLoaderX.ipa.

How is iLoader X related to SideInstaller?

iLoader X is a fork of SideInstaller by FrizzleM, kept up to date with it, with its own name, bundle ID, icon and look. It installs beside SideInstaller and shares nothing with it. Problems with iLoader X belong in its own GitHub issues, not SideInstaller's.

Is it safe to type my Apple ID into it?

The official builds are only on this site and on github.com/iamgasgass/iLoaderX, built in the open by GitHub Actions from the source you can read there. The password stays in the iPhone's keychain and goes only to Apple. A copy from anywhere else may have been changed.
